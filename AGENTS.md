# Daily Discord post: explicit opt-in only

The daily Discord post is intentionally kept focused. Do not add any new section, reminder, statistic, announcement, feature promotion, game result, link, mention, or other content unless the user has specifically discussed and explicitly agreed to include that content in the daily post.

- General requests to improve the website, add features, automate updates, or make the experience smoother do not authorize additions to the daily post.
- If there is no explicit agreement about a proposed addition to the daily post, leave it out. Build the website feature independently.
- This applies to the scheduled post, updates to an existing post, website-generated Discord text, bot integrations, and fallback posting paths.
- Preserve already-agreed schedule content and existing agreed reminders. Do not treat the existence of a new website feature as permission to promote it in Discord.
- The Anime-Börse section was explicitly removed at the user's request on 2026-11-15. Keep it out unless the user explicitly reverses that decision.
- Fixing formatting or correctness of existing approved content is allowed; adding a new type of content is not.

When working on a daily-post change, identify the specific user request that authorizes any new content before implementing it.
